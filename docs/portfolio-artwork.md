## Generated conceptual artwork

File: public/projects/portfolio/vulnerability.webp. Generated with the built-in imagegen tool; no input reference image. The project README says source-data integration is pending, so the portfolio status reflects that. This cover is not a map, result or screenshot.

Prompt:

Use case: stylized-concept. Asset: landscape 3:2 portfolio cover for NexoVibe project 'Vulnerabilidade em Cabo Delgado', a work-in-progress R pipeline combining displacement, environment and socioeconomic indicators. Create an elegant editorial 3D paper-relief illustration of layered abstract terrain, small settlement shapes and flowing migration paths, viewed obliquely, on deep charcoal #0b1418. Mint green and pale teal terrain, a few muted amber markers, quiet cinematic studio light and tactile contour lines. Balanced central composition, clear silhouette readable as a small website thumbnail. It must be openly conceptual, not a real map or screenshot. No geographic boundaries, no statistical values, no chart, no people, no distress imagery, no writing, letters, logos or watermark. All important content inside central 80%; restrained premium technology portfolio aesthetic.
